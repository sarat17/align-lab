# Muestras

Esta carpeta es para tus imágenes de prueba. Para probar rápido, usa una foto de un documento, cartel o cuadro (escena plana) y otra tomada desde un ángulo distinto: la primera como **plantilla**, la segunda como **entrada**.

- Solo añade imágenes que tengas derecho a usar, sin datos personales ni sensibles.
- El `.gitignore` excluye `samples/*.png|jpg|jpeg|tif|tiff` para no subirlas por accidente; si quieres versionar una muestra concreta, quita esa regla o usa `git add -f`.
- Sin imágenes propias, las pruebas automatizadas (`tests/`) generan imágenes sintéticas por código.
